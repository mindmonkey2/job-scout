# Verified facts for bids

Copy this file to `my_profile.md` (git-ignored) and replace the examples with your own facts.

Only the facts under "Verified" may appear in a proposal as plain statements.
Anything under "Unverified" may appear only as a [bracketed placeholder] that you confirm or delete before sending.
Move a fact to "Verified" only after checking it against real code, a live link or a document you can show a client.

## Verified (you can prove these)

- Example: I built and maintain a Flutter app with a Firebase backend (Auth, Firestore, Cloud Functions).
- Example: My public GitHub has a working Python scraper with tests: https://github.com/<you>/<repo>
- Example: I write Firestore security rules per role, with automated rule tests.

## Unverified (placeholders only)

- Example: Years of experience
- Example: Side projects that aren't finished or public yet

## Never claim

- Reviews or completed jobs you don't have
- Past client work of any kind, unless it is listed under Verified
- Skills you haven't used in real code
- Languages you can't work in
